# tno-game-logs

千年帝国 (TNO) 策略游戏 — 开发日志 / 设计文档 / 攻略档案

> 基于 TNO (The New Order: Last Days of Europe) 架空世界观的网页策略游戏。时间跨度 1962 — 2000，共 156 回合。玩家扮演德意志帝国总理，在冷战的"三极世界"中决定帝国的命运。

⚠️ 本游戏基于 TNO 架空世界观创作，纯属虚构历史推演。游戏内容旨在探讨极权主义的后果与历史教训，绝无任何政治立场或意识形态宣传意图。
