## 🎮 游戏简介

基于 TNO（The New Order: Last Days of Europe）架空世界观的网页策略游戏。
时间跨度 1962 — 2000，共 156 回合。玩家扮演德意志帝国总理，
在冷战的"三极世界"中决定帝国的命运。

> ⚠ 本游戏基于 TNO 架空世界观创作，纯属虚构历史推演。
> 游戏内容旨在探讨极权主义的后果与历史教训，绝无任何政治立场或意识形态宣传意图。

## 🌟 游戏特性

- **时间跨度**：1962Q1 — 2000Q4，共 156 回合
- **工业系统**：8 种民工业 + 9 种军工业建筑
- **威慑系统**：综合威慑与核威慑，影响外交与结局
- **5 条路线**：施佩尔（改革派）/ 鲍曼（保守派）/ 戈林（军国派）/ 海德里希（党卫军）/ 斯派达尔（意外）
- **15 种结局**：从民主化改革的"帝国之春"到核子末日的"诸神黄昏"
- **剧情事件链**：登月庆典、希特勒之死、德国内战、勃艮第危机、核军备竞赛、1989 核危机等
- **多难度**：简单 / 普通 / 困难 / 地狱
- **存档系统**：5 个手动槽 + 1 个自动槽
- **纯前端**：HTML/CSS/JS 无依赖，浏览器打开即玩
