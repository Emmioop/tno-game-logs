# 开发对话 · 第 03 卷 · 存档功能

> 给游戏加上多槽位存档系统，支持开始页面载入存档。

---

## 背景

游戏原本没有存档功能，玩家刷新页面就丢失进度。
开发者要求：
1. 游戏内有保存弹窗
2. 开始页面可以载入存档

**开发者：**
> "先回到游戏开发上。图1这里同时设计一个载入存档。图2这里设计可以任意载入存档"

---

## 设计方案

### 存档槽位

```
6 个槽位：
├── 槽位 0：自动存档（每回合自动保存）
├── 槽位 1：手动存档 1
├── 槽位 2：手动存档 2
├── 槽位 3：手动存档 3
├── 槽位 4：手动存档 4
└── 槽位 5：手动存档 5
```

### 存储方式

- **LocalStorage** —— 浏览器本地存储
- **前缀**：`tno_save_` (存档) / `tno_meta_` (元数据)
- **元数据**：保存时间、年份、路线、难度（用于列表显示）

### 存档内容

```javascript
{
    version: 1,                  // 存档版本号
    savedAt: "2026-08-03T...",   // 保存时间
    state: {                     // 游戏状态
        turn, year, quarter,
        resources: { money, stability, deterrence, ... },
        relations: { russia, ofn, ... },
        flags: { ... },
        _crisis: { stab0, debt, deter },
        ...
    },
    nations: {                   // 国家模拟数据
        GER: { gdp, army, ... },
        RUS: { ... },
        USA: { ... }
    },
    crisis: { ... }              // 危机状态
}
```

### 保存弹窗

游戏内按"保存"按钮 → 弹出槽位选择：
- 显示 6 个槽位
- 每个槽位显示：存档名 / 保存时间 / 年份季度 / 路线 / 难度
- 空槽位显示"空"
- 点击槽位 → 确认覆盖 → 保存

### 开始页面载入

开始页面"载入存档"按钮 → 弹出槽位选择：
- 只显示有存档的槽位
- 点击 → 加载 → 进入游戏

## 自动存档策略

- **触发时机**：每回合结束时
- **槽位**：槽位 0（自动存档）
- **覆盖**：自动覆盖上一次自动存档

```javascript
// game.js 推进回合后
Game.advanceTurn();
SaveSystem.save(0);  // 自动存档
```

## 兼容性处理

### 存档版本号

```javascript
const SAVE_VERSION = 1;

load(slotId) {
    const data = JSON.parse(localStorage.getItem(...));
    if (data.version !== SAVE_VERSION) {
        // 提示玩家存档版本不兼容
        return null;
    }
    // ...
}
```

### 数据完整性

- 序列化前去除函数和临时字段
- 仅保留可序列化的数据
- gdpHistory 仅保留最近 40 季度（避免存档过大）
