# 开发对话 · 第 01 卷 · 失败结局优化

> 玩家反馈"一回合就被秒杀"，AI 协助重做失败结局判定逻辑。

---

## 背景

游戏上线后玩家反馈：失败结局判定太敏感。
稳定度、资金或威慑值单次跌破阈值就立即触发结局，导致玩家体验很差。

**开发者：**
> "优化一下失败结局判定"

---

## 问题分析

### 原逻辑的问题

```javascript
// 原来的逻辑（伪代码）
if (stability < 10) {
    endGame('collapse');  // 一回合就崩
}
if (money < -100) {
    endGame('economic_collapse');  // 一次赤字就破产
}
if (deterrence < 20 && hostile) {
    endGame('invasion');  // 威慑一低就被入侵
}
```

**问题：**
1. **单次跌破即触发** —— 没给玩家挽回机会
2. **没有预警** —— 玩家不知道危机要来了
3. **难度无差异** —— 简单和地狱一样容易崩
4. **体验差** —— 辛辛苦苦打几十回合，一回合归零

---

## 解决方案

### 1. 引入危机计数器

```javascript
s._crisis = {
    stab0: 0,   // 稳定度低于阈值连续回合
    debt: 0,    // 负债超过阈值连续回合
    deter: 0,   // 威慑低于阈值且敌对关系连续回合
};
```

### 2. 多阶段预警

每个危机分 3 个阶段：
- **阶段 1（黄色预警）**：刚进入危险区，提醒玩家
- **阶段 2（橙色预警）**：持续恶化，强烈警告
- **阶段 3（红色触发）**：真的崩了

### 3. 难度分级保护

不同难度有不同的"地板值"：
- 简单：保护更多，给玩家挽回时间
- 地狱：几乎无保护，但仍有连续回合要求

---

## 具体实现

### 稳定崩溃（collapse）

```javascript
// 阈值
const stabDangerThresh = 15;    // 危险线
const stabCriticalThresh = 10;  // 临界线

if (r.stability <= stabDangerThresh) {
    cc.stab0++;
    
    // 阶段 1：低稳定持续 3 回合 → 黄色预警
    if (cc.stab0 === 3 && r.stability > stabCriticalThresh) {
        addNews('⚠ 政局动荡：民众支持率持续走低...', 'crisis');
    }
    
    // 阶段 2：稳定 < 10 持续 5 回合 → 橙色预警
    if (cc.stab0 >= 5 && r.stability <= stabCriticalThresh) {
        if (cc.stab0 === 5 || cc.stab0 % 4 === 0) {
            addNews('🚨 危机警报：稳定度极低，奴隶暴动、黑市失控...', 'crisis');
        }
    }
    
    // 阶段 3：稳定归零且超过难度保护 → 触发崩溃
    if (r.stability <= diff.stabFloor && r.stability <= 0) {
        if (cc.stab0 >= 2 || diff.stabFloor >= 0) {
            endGame('collapse');
        }
    }
} else {
    // 回暖通知
    if (cc.stab0 >= 5) {
        addNews('✅ 局势回稳：政府成功平息风波', 'economy');
    }
    cc.stab0 = 0;
}
```

### 经济崩溃（economic_collapse）

```javascript
// 软阈值（连续触发）/ 硬阈值（一回合触发）
const softDebt = (difficulty === 'hell' || difficulty === 'hard') ? -80 : -100;
const hardDebt = (difficulty === 'hell') ? -200 : -250;

if (r.money <= softDebt) {
    cc.debt++;
    
    // 连续 2 回合 → 黄色预警
    if (cc.debt === 2) {
        addNews('⚠ 赤字警报：帝国财政极度紧张...', 'crisis');
    }
    
    // 连续 3 回合以上 → 橙色预警（每隔几回合催一下）
    if (cc.debt >= 3 && (cc.debt === 3 || cc.debt % 4 === 0)) {
        addNews('🚨 帝国赤字严重：军队薪资拖欠...', 'crisis');
    }
    
    // 最终触发：连续 3 回合软阈值 OR 1 回合硬阈值
    if (cc.debt >= 3 || r.money <= hardDebt) {
        endGame('economic_collapse');
    }
}
```

### 威慑崩盘被入侵（invasion）

```javascript
// 威慑低迷 + 敌对关系 连续触发
const deterSoft = Math.max(diff.deterFloor, 15);
const hasHostile = s.relations.russia < -50 || s.relations.ofn < -50;

if (r.deterrence <= deterSoft && hasHostile) {
    cc.deter++;
    
    // 连续 2 回合 → 外交危机预警
    if (cc.deter === 2) {
        const enemy = s.relations.russia < -50 ? '俄罗斯' : '美国';
        addNews(`⚠ 外交危机：${enemy}已察觉帝国威慑疲软...`, 'crisis');
    }
    
    // 连续 4 回合 → 战争预警
    if (cc.deter === 4) {
        addNews(`🚨 战争预警：${enemy}情报判断帝国不堪一击！`, 'crisis');
    }
    
    // 连续 6 回合（1年半）→ 真正入侵
    if (cc.deter >= 6) {
        endGame('invasion');
    }
}

// 地狱难度特殊：威慑 ≤ 0 连续 2 回合直接崩
if (difficulty === 'hell' && r.deterrence <= 0) {
    cc.hellDeter = (cc.hellDeter || 0) + 1;
    if (cc.hellDeter >= 2) {
        endGame('invasion');
    }
}
```

## 视觉反馈

危机新闻有特殊样式：
- **黄色背景**（阶段 1 预警）
- **橙色背景**（阶段 2 预警）
- **红色渐变背景 + 脉冲动画**（阶段 3 触发）

回暖新闻用绿色背景，给玩家正向反馈。

## 效果

优化后：
- ✅ 玩家有 **2~6 回合** 的预警时间挽救危机
- ✅ 难度差异明显（简单更宽容，地狱更残酷）
- ✅ 视觉反馈清晰（黄→橙→红）
- ✅ 回暖有正向反馈（绿色新闻）
- ✅ 不再有"一回合秒杀"的差体验
