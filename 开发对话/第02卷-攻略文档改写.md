# 开发对话 · 第 02 卷 · 攻略文档改写

> 把攻略从 Markdown 技术文档改写为纯中文公开发布版。

---

## 背景

游戏初版的攻略文档包含：
- Markdown 表格、代码块
- 英文变量名（如 `stability`、`deterrence`）
- 技术术语（如 `JSON`、`state`）

开发者要公开发布攻略，但原版不适合非技术玩家阅读。

**开发者：**
> "攻略写成文字版的，不要带英文，我要发布的"

---

## 改写原则

1. **纯中文** —— 移除所有英文标识
2. **自然段落** —— 不用 Markdown 表格/代码块
3. **通俗语言** —— 技术术语转化为日常表达
4. **背景补充** —— 加游戏背景和剧情引导
5. **作者信息** —— 加作者和版本号

---

## 改写示例

### 改写前（技术版）

```markdown
## 结局触发条件

| 结局 | 触发条件 | 评价 |
|------|---------|------|
| 帝国之春 | stability >= 70 && deterrence >= 60 | 民主化成功 |
| 长夜将尽 | peace_mediator && stability >= 65 | 三极和平 |
```

### 改写后（公开发布版）

```
帝国之春（改革胜利）
    条件：稳定度七十以上，威慑六十以上，与自由世界缓和成功
    评价：帝国和平转型，民主化成功

长夜将尽（黄金结局，覆盖其他所有结局）
    条件：第三次大战危机中成功斡旋调停（和平缔造者）且稳定度六十五以上
    评价：帝国的最好结局——三极冷战和平落幕，世界走向共存
```

## 移除的内容

| 原内容 | 处理 |
|--------|------|
| Markdown 表格 | 改为缩进列表 |
| 代码块（```） | 改为普通文字描述 |
| 英文变量名 | 改为中文（`stability` → 稳定度） |
| 文件路径 | 移除（玩家不需要知道） |
| 技术术语 | 转化为通俗表达 |
