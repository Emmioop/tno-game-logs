## 📊 资源系统

### 主要资源

| 资源 | 范围 | 说明 |
|------|------|------|
| 资金 | -∞ ~ +∞ | 负数表示债务 |
| 稳定度 | 0 ~ 100 | 低于阈值有崩溃风险 |
| 综合威慑 | 0 ~ 100+ | 影响外交与结局 |
| 核威慑 | 0 ~ 100+ | 核打击能力 |

### 资金收支

```
每季度：
  收入 = 税收 + 工业产出 + 资源销售
  支出 = 军队维护 + 建筑维护 + 政策成本 + 奴隶口粮
  
  净收入 = 收入 - 支出
  money += 净收入
  
  if (money < 0):
      触发债务危机计数器
```

### 稳定度变化

```
每季度变化：
  + 政策加成
  + 工业满足度
  - 危机事件冲击
  - 赤字压力
  - 战争消耗
  
  stability = clamp(stability + delta, 0, 100)
```

## 💥 失败结局判定（v0.2 优化版）

### 1. 稳定崩溃（collapse）

**3 阶段机制：**

| 阶段 | 条件 | 效果 |
|------|------|------|
| 黄色预警 | 稳定 ≤15 连续 3 回合 | 新闻提醒 |
| 橙色预警 | 稳定 ≤10 连续 5 回合 | 强烈警告 |
| 触发崩溃 | 稳定 ≤0 且超过难度保护 | 游戏结束 |

**难度保护线：**
- 简单：stabFloor > 0（更宽容）
- 普通：stabFloor = 0
- 困难：stabFloor = 0
- 地狱：stabFloor = 0

**回暖机制：**
- 稳定回到 15 以上 → 计数器归零
- 持续 5 回合以上 → 绿色"局势回稳"新闻

---

### 2. 经济崩溃（economic_collapse）

**双阈值机制：**

| 阈值 | 简单/普通 | 困难/地狱 |
|------|----------|----------|
| 软阈值（连续触发） | -100 | -80 |
| 硬阈值（一回合触发） | -250 | -200 |

**触发条件：**
- 连续 3 回合 ≤ 软阈值
- **或** 单回合 ≤ 硬阈值

**预警：**
- 连续 2 回合 → "赤字警报"黄色新闻
- 连续 3 回合以上 → "赤字严重"橙色新闻（每 4 回合一次）

---

### 3. 入侵（invasion）

**双重条件：**
1. 威慑 ≤ deterSoft（普通 15）
2. **且** 与俄罗斯或美国敌对（关系 < -50）

**累积机制：**

| 连续回合 | 效果 |
|---------|------|
| 2 | "外交危机"黄色新闻 |
| 4 | "战争预警"橙色新闻 |
| 6 | 真正入侵，游戏结束 |

**地狱难度特殊：**
- 威慑 ≤ 0 连续 2 回合 → 直接入侵（无需敌对条件）

## ⚛️ 威慑系统

### 综合威慑计算

```
综合威慑 = 
    军事力量 × 0.4 +
    核威慑 × 0.4 +
    经济实力 × 0.1 +
    科技水平 × 0.1
```

### 核威慑

```
核威慑 = 核弹头数量 × 投射工具系数
```

- 核弹头：通过核设施生产
- 投射工具：导弹/轰炸机/潜艇

### 威慑影响

- 威慑高 → 外交关系更容易改善
- 威慑低 + 敌对 → 触发入侵风险
- 部分结局需要威慑阈值
