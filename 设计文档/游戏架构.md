## 🎮 核心模块

### 1. game.js（核心游戏逻辑）

**职责：** 游戏主循环、状态管理、回合推进、结局判定。

**关键函数：**
```javascript
Game = {
    state: { ... },              // 游戏状态
    difficulty: 'normal',        // 难度
    
    init(),                      // 初始化
    advanceTurn(),               // 推进一回合
    checkEnding(),               // 检查结局
    endGame(type),               // 触发结局
    addNews(text, type),         // 添加新闻
    getDiff(),                   // 获取难度配置
    
    // 工业
    buildBuilding(id),
    demolishBuilding(id),
    
    // 政策
    setPolicy(id, value),
    
    // 科技
    researchTech(id),
    
    // 外交
    improveRelations(country),
    worsenRelations(country),
};
```

**游戏状态：**
```javascript
state = {
    turn: 0,                     // 当前回合（0-155）
    year: 1962,                  // 年份
    quarter: 1,                  // 季度（1-4）
    
    resources: {
        money: 1000,             // 资金
        stability: 60,           // 稳定度（0-100）
        deterrence: 50,          // 综合威慑
        nuclearDeterrence: 30,   // 核威慑
        // ... 其它资源
    },
    
    relations: {
        russia: 0,               // -100 ~ 100
        ofn: 0,                  // 美国 OFN
        japan: 0,
        italy: 0,
    },
    
    flags: {
        // 剧情标记
        nuclear_holocaust: false,
        peace_mediator: false,
        // ...
    },
    
    _crisis: {                   // 危机计数器（v0.2 新增）
        stab0: 0,
        debt: 0,
        deter: 0,
    },
    
    buildings: { ... },          // 已建建筑
    policies: { ... },           // 已启政策
    techs: { ... },              // 已研发科技
    successor: 'speer',          // 继承人
};
```

### 2. ui.js（UI 渲染）

**职责：** 界面渲染、用户交互、弹窗管理。

**主要功能：**
- 渲染工业建设标签页
- 渲染国策政策标签页
- 渲染科技研发标签页
- 渲染新闻滚动栏
- 显示事件弹窗
- 显示保存/载入弹窗

**职责：** 1962-2000 年的剧情事件链。

---

### 4. nation_sim.js（国家模拟）

**职责：** 模拟 6 个主要国家的发展。

**模拟维度：**
- 经济（GDP、通胀、国库、税率）
- 政治（稳定度、支持率、腐败度）
- 军事（陆海空军、核武）
- 社会（人口、失业率、识字率、城市化、预期寿命）
- 科技（工业、科技、资源）

**AI 决策：**
- 每季度评估目标
- 调整外交/军事/经济策略
- 记录历史日志

---

### 5. save_system.js（存档系统）

**职责：** 多槽位存档管理。

**API：**
```javascript
SaveSystem = {
    SLOTS: [...],                // 6 个槽位
    serialize(),                 // 序列化
    save(slotId),                // 保存
    load(slotId),                // 加载
    delete(slotId),              // 删除
    listSlots(),                 // 列出所有槽位
};
```

## 🔄 游戏主循环

```
玩家点击"推进至下一季度"
        ↓
Game.advanceTurn()
        ├── 1. 回合 +1
        ├── 2. 计算经济（生产/消耗）
        ├── 3. 计算稳定度变化
        ├── 4. 计算威慑变化
        ├── 5. NationSim 更新所有国家
        ├── 6. 检查当前年份事件
        ├── 7. 随机事件判定
        ├── 8. 添加新闻
        ├── 9. checkEnding() 检查结局
        │       ├── 稳定崩溃？
        │       ├── 经济崩溃？
        │       ├── 入侵？
        │       └── 2000 年终局？
        ├── 10. UI 更新
        └── 11. SaveSystem.save(0) 自动存档
        ↓
等待玩家下一步操作
```
